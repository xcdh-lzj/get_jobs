# 管理工作台

Boss 主页面按任务概览、投递筛选、精准审核、招呼语与简历、黑名单、投递分析、账号与队列分区。设置面板保持挂载，跨分区切换保留未保存草稿。投递分析仅在打开时加载。

`WorkspaceEditsProvider` 管理三个独立编辑器：基础配置、审核设置、账号个人资料。统一保存先验证所有修改，再捕获各自负载并逐项调用现有接口。成功的部分更新本地基线，失败的部分保留草稿，重试只提交尚未保存的部分。基础配置不再写 `enableAi`，由审核编辑器管理该开关，避免跨接口覆盖。

黑名单增删与复制、图片简历上传、账号和登录操作即时生效；这些操作在界面中标明。黑名单刷新只更新黑名单，不能重置其它草稿。采用简历方向建议只填入草稿，由统一保存生效。

有未保存修改或配置尚未读取完整时，不能启动账号或账号队列。切换账号、从侧栏离开页面时提供保存、放弃和继续编辑；整页关闭或刷新使用浏览器原生未保存提示。

侧栏宽度和收起状态分别为 224 / 76 像素，状态存入本机浏览器。1024 像素以下使用抽屉，表单自然折为一列，分区导航可横向滚动。保存栏与分区导航在滚动时保持可访问。

## 岗位历史记录的查看方式

岗位列表中的“本地详情”和岗位名称读取当前记录已有的数据库快照，在本地对话框展示，不创建外部标签页、不请求 Boss、不启动浏览器自动化。没有完整 JD 的旧记录明确显示缺失信息，不为补齐详情访问原站。岗位描述和公司介绍始终按纯文字渲染。

“岗位链接”已恢复为标准网页链接，在新标签页打开保存的 Boss 详情地址，使用 `noopener noreferrer`。打开和复制前均只接受 HTTPS、无用户信息与非标准端口、官方域名下的岗位详情路径，原有查询参数保持不变，不尝试伪造访问参数。链接不会被预请求、轮询或自动刷新。本地详情仍提供复制公司与岗位、复制原链接。

`tests/boss-history.test.mjs` 验证外链的地址、打开方式与隔离属性，以及本地详情渲染不包含外部导航或嵌入资源。链接恢复只涉及前端，浏览器继续沿用原有的有窗口运行方式。
